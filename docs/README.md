# Documents

เอกสารที่ใช้เป็นหลักในปัจจุบัน:

- `../README.md` — ภาพรวมโปรเจกต์และวิธีติดตั้ง
- `../TASKS.md` — รายการงาน ผู้รับผิดชอบ และสถานะ
- `project_scope.md` — ขอบเขตโมเดล โปรโมชั่น และกติกาของโปรเจกต์
- `../CONTRIBUTING.md` — วิธีใช้ Git ทำงานร่วมกัน

โฟลเดอร์ `archive/` เก็บเอกสารเก่าที่อาจไม่ตรงกับแผนปัจจุบัน ห้ามใช้เป็นแหล่งหลักในการตัดสินใจ
