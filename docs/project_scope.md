# Project Scope

## เป้าหมาย

พัฒนาระบบสนับสนุนการตัดสินใจที่รวมการทำนายระยะเวลาปล่อยเช่า
การแนะนำราคาค่าเช่า การจำลองสถานการณ์ทางธุรกิจ และการประมาณรายได้

## วัตถุประสงค์โครงการ

1. เพื่อพัฒนาแบบจำลองสำหรับพยากรณ์ระยะเวลาในการปล่อยเช่า
   (Time-to-Lease Prediction) โดยใช้ข้อมูลคุณลักษณะของห้องพัก ราคาที่ตั้งเมื่อ
   เริ่มลงประกาศ ระยะห่างจากมหาวิทยาลัย สิ่งอำนวยความสะดวก คุณลักษณะของ
   โครงการ และสภาวะตลาดย้อนหลัง เพื่อประมาณระยะเวลาที่คาดว่าจะใช้ในการหา
   ผู้เช่าได้สำเร็จของแต่ละยูนิต และสนับสนุนการบริหารห้องว่างของแต่ละโครงการ
2. เพื่อพัฒนาโมเดลแนะนำราคาค่าเช่าที่เหมาะสม (Rental Price Recommendation)
   โดยวิเคราะห์ปัจจัยที่เกี่ยวข้อง เช่น ขนาดห้อง ชั้น ระยะห่างจากมหาวิทยาลัย
   สิ่งอำนวยความสะดวก และสภาวะตลาด เพื่อช่วยกำหนดราคาที่เหมาะสมและเพิ่ม
   ประสิทธิภาพในการปล่อยเช่า
3. เพื่อพัฒนาระบบ What-if Simulation สำหรับจำลองสถานการณ์ทางธุรกิจ โดยศึกษา
   ผลกระทบจากการเปลี่ยนแปลงของตัวแปรสำคัญ เช่น ราคาค่าเช่า โปรโมชั่น
   สิ่งอำนวยความสะดวก และสภาวะตลาด ต่อระยะเวลาการปล่อยเช่าและรายได้
   ประมาณการของโครงการ
4. เพื่อพัฒนาระบบสนับสนุนการตัดสินใจด้วย AI ในรูปแบบ Web Application โดย
   บูรณาการผลลัพธ์จากแบบจำลองและระบบ What-if Simulation เข้ากับ Dashboard
   และฟังก์ชันการวิเคราะห์ เพื่อให้ผู้บริหารสามารถติดตามข้อมูล ประเมินสถานการณ์
   และใช้ข้อเสนอแนะเชิงธุรกิจประกอบการตัดสินใจในการบริหารโครงการ

## กติกาหลัก

1. ใช้ข้อมูลใน `data/raw/` เป็นข้อมูลต้นฉบับแบบอ่านอย่างเดียว
2. เก็บผลการทำความสะอาดไว้ใน `data/processed/`
3. สร้าง Modeling Dataset ใหม่ทุกครั้งด้วยโค้ด ไม่แก้ CSV ด้วยมือ
4. แบ่ง Train, Validation และ Test ตามเวลาเดียวกันทุกโมเดล
5. เลือกโมเดลจาก Validation และใช้ Test เพียงครั้งเดียวหลังล็อกโมเดล
6. ตรวจสอบ Data Leakage โดยถามว่าตัวแปรนั้นทราบแล้วหรือยังก่อนเวลาทำนาย
7. โปรโมชั่นรุ่นแรกจำกัดเฉพาะสิ่งที่แปลงเป็นผลกระทบด้านราคาได้
8. ตัวเลขรายได้จากระบบเรียกว่า “รายได้ประมาณการ” ไม่ใช่กำไรจริง

## โปรโมชั่นในรุ่นแรก

- ส่วนลดค่าเช่าเป็นเปอร์เซ็นต์
- ส่วนลดค่าเช่าเป็นจำนวนเงิน
- ฟรีค่าเช่าบางเดือน
- ส่วนลดช่วงแรกของสัญญา

โปรโมชั่นที่เป็นของแถม บริการ หรือสิทธิประโยชน์ที่ไม่มีข้อมูลต้นทุนจะยังไม่ใช้เป็น Feature ฝึกโมเดล
